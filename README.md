
# ✈️ TripNest – Travel Planner & Travel App

TripNest is a modern UI/UX travel planning application designed in **Figma**. The app helps users search destinations, book flights and hotels, manage trips, and enjoy a seamless travel planning experience.

---

## 📖 Project Overview

TripNest is designed to simplify travel planning by bringing multiple travel services into one easy-to-use mobile application. The project focuses on creating an intuitive and visually appealing user interface using Figma.

---

## 🎯 Objectives

- Design a user-friendly travel application.
- Simplify trip planning and booking.
- Create an attractive and modern UI.
- Improve user experience through easy navigation.
- Provide an all-in-one travel solution.
